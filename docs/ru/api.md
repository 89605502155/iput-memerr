# Справочник API (iput-memerr 0.0.1)

## `MemoryUncertainty(components, formula, **параметры)`

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `components` | все семь | учитываемые компоненты, подмножество `COMPONENTS` |
| `formula` | `"linear"` | `linear`, `rss` или `gum` |
| `instrument_rel` | `0.01` | относительная точность измерительной системы (условное значение, калибруется на стенде) |
| `normal_k` | `2.0` | делитель для нормальных компонент в `gum` (2 соответствует охвату 95 %) |
| `page_size` | `4096.0` | байт в странице памяти, гранулярность хранимого счётчика |
| `clock_jitter_s` | `0.001` | джиттер часов, с (условное значение) |
| `read_latency_s` | `0.0` | время чтения счётчика, с; в погрешность момента входит половина |
| `round_step` | `1.0` | шаг округления хранимого значения, байты |
| `dtype` | `"float64"` | тип хранения: `float16`, `float32` или `float64` |
| `shared_fraction` | `0.0` | доля разделяемых страниц, учтённых в значении |
| `sampling_factor` | `0.5` | доля размаха соседних отсчётов, переходящая в погрешность дискретизации |
| `coverage` | `1.0` | коэффициент охвата для `gum` |

## `evaluate(value, *, timestamp=None, slope=None, neighbours=None)`

* `value`: число или одномерный вектор показаний памяти, байты. Нефинитные и отрицательные значения дают `ValueError`.
* `timestamp`: моменты показаний, с, той же формы, для вектора строго возрастают. Нужны компоненте `time`, если не задан `slope`.
* `slope`: производная памяти по времени, байты в секунду, той же формы.
* `neighbours`: пара `(предыдущие, следующие)` массивов той же формы. Для вектора соседи берутся из ряда, края дублируются. Для скаляра нужны компоненте `sampling`.

Возвращает `UncertaintyResult`: поля `value`, `left`, `right`, `components` (словарь имя → `(left, right)`), `formula`; свойства `lower`, `upper`, `symmetric`; метод `to_dict()`.

## Ошибки

* `TypeError`: нечисловой вход или логический параметр.
* `ValueError`: неверная форма, отрицательные или нефинитные значения, неизвестная компонента или формула, параметр вне диапазона, нет моментов времени или соседей для включённой компоненты.
