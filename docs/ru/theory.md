# Модель погрешности измерения

Пусть `x_i` показание памяти виртуальной машины в момент `t_i`. Для каждого показания библиотека даёт левую полуширину `L_i` и правую полуширину `R_i`, так что истинная величина лежит в `[x_i - L_i, x_i + R_i]` при принятых допущениях компонент.

## Компоненты

1. **instrument** (измерительная система). Читатель счётчика имеет относительную точность `r`. Полуширина `r·x_i`, нормальное распределение с охватом `k`.
2. **storage** (хранилище). Счётчик хранится страницами памяти размера `P`. Частично занятая страница может быть учтена либо нет, поэтому полуширина `P/2`, равномерное распределение.
3. **time** (момент времени). Показание относится к моменту `t_i`. Джиттер часов `δ` и половина времени чтения `τ` смещают момент на `δ + τ/2`. Полуширина `|s_i|·(δ + τ/2)`, где `s_i` наклон `dx/dt` (центральные разности ряда или заданный наклон).
4. **sampling** (дискретизация). Отсчёт может пропустить локальный пик или впадину. По соседям `p_i` и `n_i` односторонние границы `L_i = c·max(0, x_i - min(p_i, n_i))` и `R_i = c·max(0, max(p_i, n_i) - x_i)`, где `c` параметр `sampling_factor`. Локальный пик даёт левую границу, локальная впадина правую.
5. **rounding** (округление). Значение записано с шагом `q`, полуширина `q/2`, равномерное распределение.
6. **float** (представление). Хранимое значение имеет относительную ошибку не больше машинной точности типа `u`: `2^-11` для float16, `2^-24` для float32, `2^-53` для float64. Полуширина `u·x_i`, равномерное распределение.
7. **definition** (определение величины). Если доля `f` значения приходится на разделяемую память, частная часть лежит в `[x_i·(1 - f), x_i]`. Левая полуширина `f·x_i`, правая ноль.

## Сложение компонент

Пусть `L_i^(j)` и `R_i^(j)` границы компоненты `j`, а `d_j` делитель её распределения (`√3` для равномерного, `k` для нормального):

* `linear`: `L_i = Σ_j L_i^(j)`, `R_i = Σ_j R_i^(j)`;
* `rss`: `L_i = sqrt(Σ_j (L_i^(j))²)`, так же для `R_i`;
* `gum`: `L_i = c_охв·sqrt(Σ_j (L_i^(j)/d_j)²)`, так же для `R_i`, `c_охв` коэффициент охвата.

Значения по умолчанию `instrument_rel` и `clock_jitter_s` условные и должны быть заменены значениями, откалиброванными на стенде.
