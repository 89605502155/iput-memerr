# iput-memerr

Асимметричные оценки погрешностей измерения потребления оперативной памяти виртуальных машин.

English version: [README.md](README.md). Документация: [docs/ru](docs/ru/api.md), [docs/en](docs/en/api.md).

## Что делает библиотека

Библиотека принимает число или вектор показаний памяти (байты) и для каждого показания возвращает левую и правую полуширины погрешности. Они могут различаться. Семь компонент погрешности измерения моделируются отдельно, у каждой есть обоснование в документации:

| Компонента | Источник погрешности | Вид границы |
|---|---|---|
| `instrument` | точность измерительной системы (чтение счётчика) | симметричная, относительная |
| `storage` | гранулярность хранимого счётчика (страницы памяти) | симметричная, абсолютная |
| `time` | джиттер часов и время чтения, умноженные на локальный наклон | симметричная, зависит от наклона |
| `sampling` | отсчёт может пропустить пик или впадину ряда | асимметричная, по соседним отсчётам |
| `rounding` | округление значения при записи | симметричная, абсолютная |
| `float` | представление чисел с плавающей точкой (float16, float32, float64) | симметричная, относительная |
| `definition` | разделяемые страницы учтены в значении, но не принадлежат ВМ | односторонняя |

Параметры выбирают учитываемые компоненты (`components`) и правило их сложения (`formula`): `linear` (сумма границ), `rss` (корень из суммы квадратов) и `gum` (корень из суммы стандартных неопределённостей по JCGM 100). Компоненты можно включать и выключать по одной, чтобы изучить их вклад.

## Установка

```bash
pip install iput-memerr
```

Нужны Python 3.11–3.14 и NumPy 2.0 или новее.

## Быстрый старт

```python
import numpy as np
from iput_memerr import MemoryUncertainty

values = np.array([512e6, 530e6, 498e6])          # байты
times = np.array([0.0, 1.0, 2.0])                # секунды

model = MemoryUncertainty(components=("instrument", "sampling", "float"), formula="rss")
res = model.evaluate(values, timestamp=times)
print(res.lower, res.upper)                       # границы по точкам
print(res.symmetric)                              # False там, где левая и правая части различны
```

Для одного числа работает то же, но компоненте дискретизации нужны соседние отсчёты:

```python
res = MemoryUncertainty(components=("sampling",)).evaluate(512e6, neighbours=(500e6, 520e6))
```
